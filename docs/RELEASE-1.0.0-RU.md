# Battery Monitor 1.0.0 — Domovoi Assistant

Статус: кандидат на стабильный выпуск. Не публиковать как latest до проверки Windows. Установщик и манифест собираются у издателя с прежним ключом.

## Что входит

- Фирменный интерфейс Night Workshop, светлая/тёмная/системная темы, RU/UK/EN.
- Домовой: интерактивная физика, уникальные сцены, социальные таблички.
- Реакции на заряд 20/10/5%, рост показаний, достижение 100%, обнаружение и потерю сигнала, совместимость, обновления.
- Быстрые действия, переход к карточке устройства, журнал событий, приблизительная оценка оставшегося времени. История только за текущий запуск.
- Всплывающие предупреждения вне окна — по выбору пользователя, выключены по умолчанию.
- Сохранены два режима виджета, диагностика и подписанные обновления.

## Совместимость

AJAZZ AJ179 APEX (USB-приёмник/док) проверен разработчиком на более ранних версиях. Logitech G435 (USB-приёмник) определяется, автоматический процент недоступен. Bluetooth-наушники, DualShock 4, DualSense, другие контроллеры и устройства — экспериментальные и не проверены по моделям. Проверки Bluetooth перенесены до появления адаптера. Не обещать универсальную совместимость. См. [COMPATIBILITY.md](COMPATIBILITY.md).

## Контроль перед выпуском

- [ ] Скачать чистые исходники этого кандидата (не Animation Lab). Закрыть предыдущую программу через трей.
- [ ] Запустить `test-updates.cmd`: протокол обновления, нормализация заряда, реальные тесты логики BatteryAssistant, уникальные состояния. Все тесты должны завершиться успешно.
- [ ] Запустить `build-windows.cmd`, открыть `publish\BatteryMonitor.exe`. Проверить доступный AJAZZ, виджет, трей, сохранение настроек, обе темы, языки, изменение размеров окна.
- [ ] Проверить перетаскивание за разные части тела, отсутствие артефактов, остановку/запуск действий, все социальные таблички, помощника, переходы и уведомления. Отдельно проверить анимации через приватную панель, не включая её в официальный установщик.
- [ ] Проверить, что неизвестные проценты не выдаются за реальные, режим «Не беспокоить» и опциональные уведомления работают.
- [ ] В чистой папке исходников восстановить прежний `update-config.json` через `configure-updates.cmd`, указав `kross873/battery-monitor-releases`. Если ключ отсутствует, остановиться и восстановить резервную копию. Не создавать новый ключ.
- [ ] Запустить `make-release.cmd`. Он выполняет самотесты, собирает установщик и подписывает манифест. Не использовать приватный DEV-проект.
- [ ] Проверить `release\BatteryMonitor-1.0.0-Setup.exe` на Windows: чистая установка, обновление поверх 0.12.0, сохранение настроек, запуск/выход, удаление, лицензии. Проверить оба режима установки, Windhawk отдельно.
- [ ] Сохранить проверенные исходники в main, создать тег `v1.0.0` на соответствующем коммите, затем создать релиз с этим тегом в [репозитории выпусков](https://github.com/kross873/battery-monitor-releases/releases).
- [ ] Загрузить ровно проверенные `BatteryMonitor-1.0.0-Setup.exe` и `update.json`; приложить ссылку на соответствующие исходники. Не изменять EXE после подписи. Проверить, что обновление из официальной 0.12.0 обнаруживается и после установки 1.0.0 новых обновлений нет.
- [ ] Назначить latest только для проверенного стабильного выпуска.

Манифест RSA не является Authenticode-подписью Windows. Не отключайте защиту Windows. Закрытый ключ не передаётся в чат, GitHub, установщик или архив.
